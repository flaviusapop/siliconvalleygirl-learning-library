## Actionable learnings

1. Create a portable folder for one workflow containing its source material, performance measures, voice guidance and current strategy; restrict access to appropriate team members.
2. Write a shared context file and a separate task checklist, then test both against a real production assignment before expanding automation.
3. Schedule a narrow research task that produces a draft for human review, with explicit inputs, timing and a destination.
4. Choose one measurable publishing signal and route a useful alert to its owner; review whether it leads to better decisions before adding more triggers.
